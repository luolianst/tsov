# 转录修正批与验证纪律（深入页）

## 常用两条批（M-V6 任务1 实测口径）
1. **噪声短音**：< 55ms 且 velocity ≤ 0.45 → 删除
2. **调外吸附**：调外 且 |deviation_cents| ≥ 42 → 吸到最近调内音

用 `edit_score` 的 annotations 确定性执行；**不要**用自然语言让模型自由发挥。

## 验证纪律
- 修正后：音高集合 ⊆ 目标音阶 + 总音数对账 + 渲染试听；
- 对齐验证：谱面音符起点 vs 原唱 onset 强度峰（p75）80ms 容差命中率 + 平移对照
  （±1.5 / 2.5 / 3.5s 命中率应显著下降）；
- 现场观众素材（掌声/合唱）别用全带包络互相关（会失效）。
