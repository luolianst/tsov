# 转录底座选用（game / rmvpe）（深入页）

| 场景 | 底座 | 备注 |
|---|---|---|
| 成品歌（带歌词/混合伴奏） | `game` | 带词底座；对无词哼唱有八度/检出风险 |
| 纯人声清唱 / 无词哼唱 | `rmvpe` | 哼唱首选；输出纯音高轨迹 |

- 换模型 = `tsov/dsp/backends/` 加一文件（注册表模式）。E 批起另有四声部：鼓 = adtof、贝斯/其他 = mt3。
- GAME GPU 事实：一直在 GPU（Lightning 自动选 CUDA）；瓶颈是启动/权重加载固定开销（短片段摊薄）。
- 耗时量级：GAME 整首 ~36s（4:42 素材实测）；RMVPE 短片段秒级。
