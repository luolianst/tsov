# 旋律改谱（edit_score 进阶用法）

## 动作选择（先选对动词，再让程序执行）
- 整体平移 → `transpose` 一个动作搞定，**不要**逐个改 pitch
- 少数音修正 → `pitch`（value = 绝对音高）
- 增/删 → `add` / `delete`（**delete 从后往前给**，index 不漂移）
- 只动时间 → `set_time`；时间+音高都动 → `move`

## 调式转换（如 D 多利亚）
1. 目标音阶（D 多利亚 = D E F G A B C；不要按「大调白键」想当然）
2. 只改**调外音**，每音就近 ±1 半音解决，保持旋律轮廓（上行/下行走向、节奏不变）
3. 自查：load_score 确认全部音高落音阶内 → 渲染试听

## 常见诉求 → 手法
- 「更欢快」：音区上移（transpose / 局部 +12）、缩短长音、增加跳跃音程
- 「更舒缓」：拉长时值（set_time）、减少大跳、句末下行解决
- 「保留骨架」：只改装饰与时值，不动节奏重音和轮廓拐点
- 「去量化/更人性化」：微调 start/end（±10-30ms 级），别动音高

## 硬性注意
- **精确操作（定点插入/统一移位）不要靠自然语言让模型自由发挥**——先走人工标注（annotations，确定性最高优先级），LLM 只做语义层
- 每次编辑后核对工具观测里的 `idx` 动作行（意图级 diff），逐条对上再收工
- 不要试图清空已有谱（非空输入不允许清空，会被拒绝）；重来请新建空工程
