# 从零创作旋律（空谱）

1. **定调**：先选音阶（默认 C 大调，或用户指定的调式/情绪暗示），全部音高落音阶内
2. **起步 4-8 个音**：一个 2-4 小节的动机（motif）——级进为主，大跳 ≤ 五度
3. **节奏**：先「1 拍/音」（start/end 按 tempo 换算秒）保证可听，再点缀长短对比
4. **发展**：重复动机 + 尾音变化（模进 ±2 半音或倒影）；句末落主音/属音
5. **自查**：load_score 检查音高集合 ⊆ 音阶 → render_wav 渲染试听
6. **写谱路径**：空谱 edit_score 会自动补 melody 轨；用 `add` 动作逐个加音
   （index 按序 append：0=起点，后续用当前长度；start/end 互相衔接）

## 注意
- 不要试图「清空」已有谱（非空输入不允许清空，会被拒绝）
- 单次别贪多：先 4-8 音给用户听方向，再按反馈发展——对话式创作，不是一次性交卷
