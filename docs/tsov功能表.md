# tsov 功能表 · 操作指南（用户版）

> tsov 是一个「看得见的旋律工作台」：在浏览器里打开你的乐谱，**听、改、混**，最后导出音频与 MIDI。
> 本表覆盖 2026-09-23 已上线的全部功能。｜打开方式：双击桌面 `tsov-web.bat`，浏览器会自动打开（或手动访问 `http://127.0.0.1:8790`）。

---

## 一、三分钟上手

1. **开**：顶栏左侧下拉，选一个工程（没有就 ☰ 文件 →「新建工程…」）。
2. **听**：点 ▶ 试听（或按 `空格`）；`Home` 回到开头；想循环就点 🔁 或按 `L`。
3. **改**：双击某条轨道，进入「单轨写谱」；用 ✂ 剪刀、🩹 胶水、🧽 橡皮等工具改音符，`Ctrl+C / V` 复制粘贴。
4. **混**：底部「混音台」拉推子，「效果器」加混响之类效果。
5. **出**：☰ 文件 →「导出…」→ 勾上 master / 分轨 stems / MIDI → 开始导出。

> 改错了别慌：顶栏 `↩`（或对话面板下方「撤销一步」），20 步之内随时回退。

| 位置 | 是什么 |
|---|---|
| **顶栏** | 工程选择 · ☰ 文件菜单 · 播放控制 · 速度/拍号 · 撤销/缩放/吸附 · 主题 / 设置 |

## 三、打开与管理工程

- **选择工程**：顶栏下拉直接切换。
- **新建 / 重命名 / 刷新列表**：☰ 文件。
- **导入工程**：☰ 文件 →「导入工程…」——从 `output/` 里挑一个 score.json（或贴路径），另起工程名导入（适合把别处产出的谱"回流"进来）。

## 四、听：播放与定位

| 控件 | 作用 |
|---|---|
| ▶ 试听 | 在浏览器里播放（第一次用前先点一次「渲染」生成试听音频；之后改完谱面一般会**自动重渲**） |
| 🔊 宿主 | 用电脑声卡直接播放（与浏览器试听同一套混音，等它播完或按 ⏹） |
| ⏹ | 停止（停在原地，`Home` 回开头） |
| 标尺定位 | **单击 / 拖动标尺** = 定位播放起点（拖动实时跟手；与播放轴同一套定位逻辑） |
| 🔁 循环 | **右键在标尺上拖**划出区间（**拍级吸附**，按住 `Alt` 自由）；右键双击区间清除；右键拖端点 / 拖区间中 = 调整；`L` 开关 |
| 🥁 节拍器 | 播放时按拍发声（强拍高音） |
| 渲染 | 把当前谱面离线渲染成试听 wav |

- **速度**：`♩=` 输入新 BPM（回车生效）；「跟速」勾选时音符/书签/自动化曲线一起等比缩放（默认开，DAW 习惯）；取消勾选 = 只改速度数值。
- **拍号**：输入形如 `3/4`、`6/8`。
- **电平表**：状态栏右边，L/R 两条 + 峰值保持 + CLIP 过载标记（看的是试听通路）。

## 五、看：总谱与单轨

- **总谱**：所有轨道一屏预览。左栏轨道列表与卷帘**逐行对齐**；**滚左栏 = 卷帘同步上下滚**（卷帘上滚轮仍管横向 / `Ctrl` 缩放）。单击选中、`Ctrl` 单击加选、双击进入单轨。
- **单轨写谱**：双击某轨进入；`Esc` 或左上「◀ 总谱」返回。
  - 单击左侧**其他轨道** = 灰色叠加（对照着写）；双击 = 换主轨。

## 六、改：编辑工具（单轨视图）

| 工具 | 快捷键 | 用法 |
|---|---|---|
| 🖱 智能 | `1` | 选择 / 拖动 / 手绘音符 |
| ▭ 范围 | `2` | 框选一片音符 |
| ✂ 剪刀 | `3` | 点击音符从中间切开（按住 `Alt` 临时切到剪刀） |
| 🩹 胶水 | `4` | 与后面相邻的同音结合并 |
| 🧽 橡皮 | `5` | 拖刷删除（划过即删，可撤销） |

- **吸附 / 网格**：顶栏「吸附」（1/8、1/16）与单轨工具条「网格」（1/4·1/8·1/16）——新建、拖动、量化都按它们对齐。
- **量化 + Swing**：选好网格 → 点「量化选区」把选区（没选 = 整轨）对齐网格；Swing 0~100% 给后半拍加摇摆感。
- **剪贴板**：`Ctrl+C` 复制 ｜ `Ctrl+X` 剪切 ｜ `Ctrl+V` 粘贴到播放轴位置 ｜ `Ctrl+D` 就地复制一份。
- **微推**：`←` / `→` 挪一格；`Shift+←` / `Shift+→` 挪一小节。
- **选中工具条**：点住音符时出现——半音 ♭−1/♯+1、八度 ±8、力度 ±、🗑 删除、✕ 关闭（保留选区）。
- **标注模式**：勾上后，选区操作会先攒着变成批注，随下一条对话一起发出（给对话提供上下文）。

## 七、乐段与书签

- **乐段（段道）**：谱面上方那条窄条上——拖动空白 = 新建乐段；拖段身 = 移动；拖边缘 = 拉伸（都按**拍**吸附，按住 `Alt` 自由）；双击 = 跳到段头；右键 = 菜单。
- **书签**：按 `M` 在当前位置建书签（`Shift+M` 强制建到项目层）。
- **书签列表**（左栏）：单击跳转、双击改名；乐段行有 🔁 一键设为循环区间；✕ 删除。

---

## 八、自动化（音量 / 声像曲线）

单轨视图勾上「自动化」→ 谱面底部出现曲线道：

- **点**空白 = 加一个点；**拖**点 = 移动；**双击 / 右键点** = 删除。
- 参数在「音量（0~200%）/ 声像（L~R）」间切换。
- 每笔改动单独成步，随时可撤销。曲线之间自动线性过渡。

## 九、混音（底部功能坞）

| 页签 | 怎么用 |
|---|---|
| **通道** | 当前轨道详情：音源 / 音量 / 声像 / M 静音 · S 独奏 / 效果链摘要（总谱视图下显示工程总览） |
| **效果器** | 先选**目标**（当前轨 / 某条总线 / master）→ 下拉选类型 → ＋ 加入链尾；✕ 移除单块效果。类型里含 **vst3**（加入时填插件文件路径） |
| **音源** | 换 GM 音色；或在「路径」里填 `vst3:…` / `sfz:…` 换合成器 |
| **混音台** | 每轨一条：推子（0~200%）、M/S；**Send**：「＋ Send →」选一条总线，拖动条调发送量，✕ 移除（发送是分支，不影响主输出） |
| **录音** | 选输入设备；勾「监听」可听到自己（约 30-90ms 延迟）；● 开始录制 / ■ 停止；录完自动入库（44.1k flac）并加入时间线 |

> **总线（bus)**：通过对话或命令创建（例："加一条 reverb 总线"）。创建后可作 Send 目标、可挂效果、可导出总线 stems。

## 十、音频素材与 MIDI

- **导入音频素材**：☰ 文件 →「导入音频素材…」→ 选音频文件（做参考轨 / 原曲对照）。音频轨显示为**波形块**：拖动块 = 改位置，双击 = 试听。
- **导入 MIDI**：☰ 文件 →「导入 MIDI…」→ 选 `.mid` 文件 → 作为新轨追加（GM 音色名尽量还原）。
- **导出**：☰ 文件 →「导出…」→ 勾选需要的内容：

| 勾选项 | 产物 |
|---|---|
| 混音 master | `mix.wav` |
| 每轨 stems | `stems/<轨名>.wav` |
| 总线 stems | `buses/`（工程有总线时才出） |
| MIDI Type1 | 多轨 `.mid` |
| 每轨 MIDI | `midi-stems/` |

> 产物在 `output/<工程>/exports/<时间戳>/`，每次导出一个新时间戳目录，不会互相覆盖。

## 十一、对话创作（用说话的方式改谱）

右侧对话框直接说人话，例如：

- 「把这段改成 D 多利亚调式」
- 「旋律整体升 2 个半音」
- 「第 3 轨的力度调成 0.7 附近」

- **快捷命令** 下拉：内置示例（LLM 语义编辑 / 命令层直编），选好点「执行」。
- **🆕 新会话**：结束当前线程、下一轮起新会话（历史保留可回看）；**📥 导入**：载入历史会话接着聊；**⏹ 停止**：中止进行中的对话。
- 对话产生的一切修改同样走版本系统——可撤销、可回滚。

---

## 十二、版本与安全网

- **撤销 / 重做**：顶栏 `↩` `↪`；对话面板也有「撤销一步」——**操作 20 步 / 对话 5 轮**窗口内零成本回退。
- **收藏 ★**：☰ 文件 →「收藏当前版本」= 永久存档点（不随日常操作清理）；「恢复收藏版本…」挑选还原。
- **听旧版**：☰ 文件 →「听旧版」下拉选旧版本，点 ▶ 只试听旧版（不影响当前版本）。
- **回滚**：对话面板底部下拉可选「最近窗口 / 收藏 / 全部 git 版本」→「恢复/回滚」；「清除 diff」收起三色对比显示。
- **自动收藏**：⚙ 设置 → 版本留存——每 N 轮自动收藏、定时收藏（按分钟）、可「应用到全部工程」。

## 十五、已知边界（先知道，不踩坑）

1. **输出为系统共享模式**，低延迟 ASIO 还没上（后续迭代）。
2. **电平表**看的是浏览器试听通路；宿主播放不经它显示。
3. **哼唱 → MIDI 自动转谱**快车道还没上线（下一批）；目前用 MIDI / 音频导入 + 手工编辑。
4. **自动化**目前只有音量、声像两条曲线。
5. **VST3 效果**：需要把插件文件放进 `vendor/vst3/`，添加效果时填插件内层路径。
6. 首次试听前先点一次「渲染」；平时改完谱面会自动重渲（偶尔弹「已重渲 …」提示属正常）。
