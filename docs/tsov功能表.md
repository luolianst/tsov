# tsov 功能表 · 操作指南（用户版）

> tsov 是一个「看得见的旋律工作台」：在浏览器里打开你的乐谱，**听、改、混**，最后导出音频与 MIDI。
> 本表覆盖 **2026-09-27** 已上线的全部功能（M-V8 收口版）。｜打开方式：双击桌面 `tsov-web.bat`，浏览器会自动打开（或手动访问 `http://127.0.0.1:8790`）。

---

## 一、三分钟上手

1. **开**：顶栏左侧下拉，选一个工程（没有就 ☰ 文件 →「新建工程…」）。
2. **听**：点 ▶ 试听（或按 `空格`）；`Home` 回到开头；想循环就点 🔁 或按 `L`。
3. **改**：双击某条轨道（**音频轨也行——进去看波形**），进入「单轨写谱」；用 ✂ 剪刀、🩹 胶水、🧽 橡皮等工具改音符，`Ctrl+C / V` 复制粘贴。
4. **混**：底部「混音台」拉推子，「效果器」加混响之类效果。
5. **出**：☰ 文件 →「导出…」→ 勾上 master / 分轨 stems / MIDI → 开始导出。

> 改错了别慌：顶栏 `↩`（或对话面板下方「撤销一步」），20 步之内随时回退。

## 三、打开与管理工程

- **选择工程**：顶栏下拉直接切换。
- **新建 / 重命名 / 刷新列表**：☰ 文件。
- **导入工程**：☰ 文件 →「导入工程…」——从 `output/` 里挑一个 score.json（或贴路径），另起工程名导入（适合把别处产出的谱"回流"进来）。
- **删除工程**：☰ 文件 →「删除当前工程…」→ 二次确认。删除是**安全删**：整目录移入 `output/.trash/`（不物理删）——要找回就把 `output/.trash/<名字>-<时间>/` 整个移回 `output/`，刷新列表即可。

## 四、听：播放与定位

| 控件 | 作用 |
|---|---|
| ▶ 试听 | 在浏览器里播放（第一次用前先点一次「渲染」生成试听音频；之后改完谱面一般会**自动重渲**） |
| 🔊 宿主 | 用电脑声卡直接播放（与浏览器试听同一套混音，等它播完或按 ⏹） |
| ⏹ | 停止（停在原地，`Home` 回开头） |
| 标尺定位 | **单击 / 拖动标尺** = 定位播放起点（拖动实时跟手；与播放轴同一套定位逻辑） |
| 🔁 循环 | **右键在标尺上拖**划出区间（**拍级吸附**，按住 `Alt` 自由）；右键双击区间清除；右键拖端点 / 拖区间中 = 调整；`L` 开关 |
| 🥁 节拍器 | 播放时按拍发声（强拍高音） |
| 渲染 | 把当前谱面离线渲染成试听 wav |

- **速度**：`♩=` 输入新 BPM（回车生效）；「跟速」勾选时音符/书签/自动化曲线一起等比缩放（默认开，DAW 习惯）；取消勾选 = 只改速度数值。
- **拍号**：输入形如 `3/4`、`6/8`。
- **电平表**：状态栏右边，L/R 两条 + 峰值保持 + CLIP 过载标记（看的是试听通路）。

## 五、看：总谱与单轨

- **总谱**：所有轨道一屏预览。左栏轨道列表与卷帘**逐行对齐**（含**文件夹行**与**折叠**——折叠的轨道两边一起收起）；**滚左栏 = 卷帘同步上下滚**（范围一致，**滚到底两边仍对齐**；滚过轨道区后卷帘下方留白；卷帘上的滚轮仍管横向 / `Ctrl` 缩放）。单击选中、`Ctrl` 单击加选、双击进入单轨。
- **单轨写谱**：双击某轨进入；`Esc` 或左上「◀ 总谱」返回。
  - **音频轨**进来看到的是**波形**（缩放/滚动同卷帘；**双击波形区 = 试听素材**）。
  - 单击左侧**其他轨道** = 灰色叠加（对照着写）；双击 = 换主轨。
  - **跨类型叠加（含音频）→ 上下分屏**：主轨在上、叠加轨在下——下区 MIDI 画灰色卷帘、音频画波形；**中间分界线可拖动**调整上下比例（约 15%~85%）；**双击下区 = 交换**主轨/叠加（上↔下对调）。标题栏显示「叠加：轨名」。

## 六、改：编辑工具（单轨视图）

| 工具 | 快捷键 | 用法 |
|---|---|---|
| 🖱 智能 | `1` | 选择 / 拖动 / 手绘音符 |
| ▭ 范围 | `2` | 框选一片音符 |
| ✂ 剪刀 | `3` | 点击音符从中间切开（按住 `Alt` 临时切到剪刀） |
| 🩹 胶水 | `4` | 与后面相邻的同音结合并 |
| 🧽 橡皮 | `5` | 拖刷删除（划过即删，可撤销） |

- **吸附 / 网格**：顶栏「吸附」（1/8、1/16）与单轨工具条「网格」（1/4·1/8·1/16）——新建、拖动、量化都按它们对齐。
- **量化 + Swing**：选好网格 → 点「量化选区」把选区（没选 = 整轨）对齐网格；Swing 0~100% 给后半拍加摇摆感。
- **剪贴板**：`Ctrl+C` 复制 ｜ `Ctrl+X` 剪切 ｜ `Ctrl+V` 粘贴到播放轴位置 ｜ `Ctrl+D` 就地复制一份。
- **微推**：`←` / `→` 挪一格；`Shift+←` / `Shift+→` 挪一小节。
- **选中工具条**：点住音符时出现——半音 ♭−1/♯+1、八度 ±8、力度 ±、🗑 删除、✕ 关闭（保留选区）。
- **标注模式**：勾上后，选区操作会先攒着变成批注，随下一条对话一起发出（给对话提供上下文）。

## 七、乐段与书签

- **乐段（段道）**：谱面上方那条窄条上——拖动空白 = 新建乐段；拖段身 = 移动；拖边缘 = 拉伸（都按**拍**吸附，按住 `Alt` 自由）；双击 = 跳到段头；右键 = 菜单。
- **书签**：按 `M` 在当前位置建书签（`Shift+M` 强制建到项目层）。
- **书签列表**（左栏）：单击跳转、双击改名；乐段行有 🔁 一键设为循环区间；✕ 删除。

## 八、自动化（音量 / 声像曲线）

单轨视图勾上「自动化」→ 谱面底部出现曲线道：

- **点**空白 = 加一个点；**拖**点 = 移动；**双击 / 右键点** = 删除。
- 参数在「音量（0~200%）/ 声像（L~R）」间切换。
- 每笔改动单独成步，随时可撤销。曲线之间自动线性过渡。

## 九、混音（底部功能坞）

| 页签 | 怎么用 |
|---|---|
| **通道** | 当前轨道详情：音源 / 音量 / 声像 / M 静音 · S 独奏 / 效果链摘要（总谱视图下显示工程总览） |
| **效果器** | 先选**目标**（当前轨 / 某条总线 / master）→ 下拉选类型 → ＋ 加入链尾；✕ 移除单块效果。类型里含 **vst3**（加入时填插件文件路径） |
| **音源** | 换 GM 音色；或在「路径」里填 `vst3:…` / `sfz:…` 换合成器 |
| **混音台** | 每轨一条：推子（0~200%）、M/S；**Send**：「＋ Send →」选一条总线，拖动条调发送量，✕ 移除（发送是分支，不影响主输出） |
| **录音** | 选输入设备；勾「监听」可听到自己（约 30-90ms 延迟）；● 开始录制 / ■ 停止；录完自动入库（44.1k flac）并加入时间线 |
| **处理链 ◈实验性** | 哼唱快车道五步链（降噪 → 响度 → 转录 → 量化 → 调内吸附）：选源音频轨 →「▶ 运行」全跑；每步可改参（快档自动顺跑 / 慢档点「应用」重跑该步及下游）；可 mute 跳过某步；跑中可取消；产物落 `chain/<时间戳>/`；跑完点链头「⇥ 进工程」= 把「转录原始 + 处理版」双轨插到源轨正下方（可撤销；重复点 = 刷新替换）；某步失败标红，可 **重试 / 改参再跑 / 跳过** |
| **AI ◈实验性** | AI 工作台（见 §十一）：**审查中心**（上下文 + 暂存区卡片：链产物 / 调参批次 / 配器草稿——试听、采纳、丢弃）+ **AI 调参**（分析事实 → 建议卡 → 勾选应用 → 对拍小结）+ **AI 配器**（风格包 + 强度档 → 生成初稿 → 试听预览 → 进工程 / 丢弃）。AI 产物一律先进暂存区，**人批才落地**（可撤销） |

> **总线（bus)**：通过对话或命令创建（例："加一条 reverb 总线"）。创建后可作 Send 目标、可挂效果、可导出总线 stems。

## 十、音频素材与 MIDI

- **导入音频素材**：☰ 文件 →「导入音频素材…」→ 选音频文件（做参考轨 / 原曲对照）。音频轨显示为**波形块**：拖动块 = 改位置；**双击块 = 进单轨看波形**（试听：进单轨后**双击波形区**）；`Ctrl` 单击 = 加入叠加（对照）。
- **剪辑音频块（总谱 / 单轨通用）**：拖块身 = **移动**（吸附网格，`Alt` 自由）｜拖左右缘 = **修剪**｜拖**上角** = **淡入 / 淡出**（左角进、右角出）｜`Alt` + 拖右缘 = **时间伸缩**（0.5×–2×，保音高）｜`Alt` 单击 = **切分**（单轨里也可用剪刀工具 ✂）。全部随时可撤销。
- **转乐谱（哼唱 → MIDI 快车道 ◈实验性）**：**右键音频轨 →「转乐谱…」**（或录音面板「转乐谱 ◈实验性」按钮）→ 自动切到处理链页签 → 点「▶ 运行」出五步产物；跑完点「⇥ 进工程」把双轨（转录原始 + 处理版）插到源轨下方。节拍工具条里可边跑边看进度。
- **新建轨道**：时间线尾部「**＋ 新建轨道**」= 加一条空 MIDI 轨（与 agent 同一命令层路径）。
- **导入 MIDI**：☰ 文件 →「导入 MIDI…」→ 选 `.mid` 文件 → 作为新轨追加（GM 音色名尽量还原）。
- **导出**：☰ 文件 →「导出…」→ 勾选需要的内容：

| 勾选项 | 产物 |
|---|---|
| 混音 master | `mix.wav` |
| 每轨 stems | `stems/<轨名>.wav` |
| 总线 stems | `buses/`（工程有总线时才出） |
| MIDI Type1 | 多轨 `.mid` |
| 每轨 MIDI | `midi-stems/` |

- **导出选项**：弹窗里可选 **位深**（16 / 24 / 32f，默认 16）；勾「**仅导出选段**」= 只导出循环区间（先把循环划好）；音频产物按样本级切片，MIDI 不受影响（仍全曲）。

> 产物在 `output/<工程>/exports/<时间戳>/`，每次导出一个新时间戳目录，不会互相覆盖。

## 十一、AI 工作台（◈实验性）

**入口已并入右侧对话栏**（原底部「AI」页签已裁撤——对话、步骤、上下文现在是一处）。总原则不变：**AI 只出初稿与建议，且一律先进「步骤」待处置，人批才落地**；采纳走与手动操作同一条命令层（可撤销）。

**① 工程上下文（折叠条）**

对话栏顶部「**工程上下文（agents.md）**」——展开可见工程 `agents.md` / 全局 `agents-user.md` 两层状态，可「生成 / 刷新」。

**② AI 动作 chips（4 颗）**

对话框上方一排：

| chip | 效果 |
|---|---|
| ＋ 分析电平 | 只读——分析结果以系统消息进对话，不改工程、不出卡 |
| ＋ 调参建议 | 生成调参批次 → 「步骤」出现**待处置**卡 |
| ＋ 配器初稿 | 默认风格包 + 标准档一键生成初稿 → 待处置卡 |
| ＋ 跑处理链 | 定位到「链」页签（跑链有入参选择，在链面板内发起） |

**③ AI 调参（给混音出建议）**

1. 点 chip 或直接对对话说 →「生成建议」→ 建议卡（类型、理由、前后值、证据）；
2. 到「**步骤**」点开待处置卡：每条建议可**一键试听**（预览渲染，不入库）；勾选要用的（默认全选）→「**⇥ 应用选中**」→ 命令层落地（音量差量按**当前值**换算，不覆盖手改）→ 出**应用小结**（对拍 ✅⚠❗）+ 一键撤销。

**④ AI 配器（风格包 → 初稿）**

1. 点「＋ 配器初稿」或缺省在对话里说（例如「用 edm 包生成一版」）——生成约 1 分钟内（LLM 段级决策 + 规则落音符；拍号与包不符会明确拒绝）；
2. 生成物在「步骤」待处置卡：「试听预览」听整段混合效果（工程零改动）；「进工程」= 各角色音轨插到旋律轨正下方（可撤销）；「丢弃」= 零残留。

> 定位提醒：**配器与调参产物都是初稿/参考**——后续结合你的意见再精细打磨（深打磨界面与另三风格包排队中）。

## 十二、对话创作（用说话的方式改谱）

右侧对话框直接说人话，例如：

- 「把这段改成 D 多利亚调式」
- 「旋律整体升 2 个半音」
- 「第 3 轨的力度调成 0.7 附近」

- **AI 动作 chips**：4 颗常用动作一键触发（见「十一、AI 工作台」）。
- **对话 ｜ 步骤 双 tab**（对话栏顶部切换）：
  - **对话**：消息流——AI 的每次修改都会附一张**变更汇总卡**（「本轮变更 · N 个动作」，统计如「修改音符 ×64 / 轨道 +1」，点开看逐条明细，可「查看 diff」「撤销本轮」）；
  - **步骤**：把 AI 做过的事和 AI 产物（调参/配器/处理链）汇成一条时间线——**一轮一卡**、默认折叠点开明细；产物卡点开就能**验收操作**（勾选应用 / 试听 / 丢弃）；角标 ●N = 待处置数。
- **🆕 新会话**：结束当前线程、下一轮起新会话（历史保留可回看）；**📥 导入**：载入历史会话接着聊；**⏹ 停止**：中止进行中的对话。
- 对话产生的一切修改同样走版本系统——可撤销、可回滚；手动操作不受影响（AI 的账本单独记）。

## 十三、版本与安全网

- **保存状态**：顶栏右侧有「**已保存 hh:mm:ss**」徽章——编辑会自动落盘，徽章时间随之刷新（「保存中…」短暂出现后转「已保存」属正常）。
- **撤销 / 重做**：顶栏 `↩` `↪`；对话面板也有「撤销一步」——**操作 20 步 / 对话 5 轮**窗口内零成本回退。
- **收藏 ★**：☰ 文件 →「收藏当前版本」= 永久存档点（不随日常操作清理）；「恢复收藏版本…」挑选还原。
- **听旧版**：☰ 文件 →「听旧版」下拉选旧版本，点 ▶ 只试听旧版（不影响当前版本）。
- **回滚**：对话面板底部下拉可选「最近窗口 / 收藏 / 全部 git 版本」→「恢复/回滚」；「清除 diff」收起三色对比显示。
- **自动收藏**：⚙ 设置 → 版本留存——每 N 轮自动收藏、定时收藏（按分钟）、可「应用到全部工程」。

## 十六、已知边界（先知道，不踩坑）
