# 术语表 —— tsov 词汇 & DAW 对照

**简体中文 | [English](glossary.md)**

tsov 有自己的小词汇表。这一页把界面（v0.1 即中文）、文档与代码里会遇到的词讲清楚，并给出最接近的通用 DAW 概念——帮你把旧习惯快速迁移过来。

> 新来的？先看 [README 快速开始](../README.zh-CN.md#快速开始)；遇到看不懂的按钮和词，再回来查。

## 工作台

| 术语 | 英文 | 说明 | DAW 里的近似物 |
|---|---|---|---|
| 工程 | project | 一首歌的文件夹——乐谱、音频、编辑历史。一个工程 = 一个 git 仓库。 | project / session |
| 轨道 | track | 一条声部：MIDI 音符，或一段音频块。 | track |
| 乐谱 | score | 音符级的歌曲数据（轨道、乐器、速度、调性）——所有修改最终落进的「可编辑真相」。 | MIDI / 钢琴卷帘数据 |
| 总线 | bus | 编组通道：多条轨汇入，其效果链作用于总和，再进主输出。 | group / bus |
| 效果链 | effect chain | 挂在轨道或总线上的有序效果器货架（内置 + VST3）。 | FX chain |
| 自动化 | automation | 参数随时间变化的曲线（如副歌前的音量爬升）。 | automation lane |
| 书签 | bookmark | 带名字的位置或区间，可随时跳回——分工程 / 文件夹 / 轨道三层。 | marker / region |
| 收藏 | favorite | 整个工程的命名检查点（底层是 git tag）——随时回跳；长迭代会自动生成。 | named versions / 存档点 |
| 回滚 | rollback | 在编辑历史里时间旅行——每个动作都有快照，不会丢东西。 | undo history（增强版） |

## 哼唱快车道（humming quick-lane）

从一段哼唱录音到可编辑音符的一键之路。每一步都是小工具：可见、可单跑、可调参——跑全链，或只跑一步。

| 术语 | 英文 | 说明 |
|---|---|---|
| 哼唱快车道 | quick-lane | 把哼唱录音变成干净音符的管线面板（dock ▸ 链页签）。通用 DAW 没有对应物——可以理解为「带向导的一键流水线」。 |
| ▶ 运行全链 | run the chain | 按顺序执行全部五步；单步也可重跑，或改参后重新应用。 |
| 降噪 | denoise | 去背景噪声（noisereduce 谱门，含 16 kHz 转码）。 |
| 响度 | loudness | 转录前把录音做响度归一（EBU R128，默认 −16 LUFS）。 |
| 转录 | transcribe | 音频 → 音符。哼唱走 RMVPE；成品人声走 GAME。 |
| 量化 | quantize | 把音符时值对齐节拍网格（网格跟随 BPM）。 |
| 调内吸附 | scale snap | 把轻微跑调的音温柔地吸回检测到的调内。 |
| 转乐谱…（实验性） | convert to score | 右键音频轨（或录音面板按钮）：给该轨挂上快车道并切到处理链面板。 |
| 采纳 | adopt | 把计算结果收进工程——作为一个真实、可撤销的编辑。 |
| 丢弃 | discard | 拒绝掉，什么都不会进工程。 |
| 试听 | audition | 决定前先听一耳朵。 |

## 与 agent 协作

| 术语 | 英文 | 说明 |
|---|---|---|
| 对话 | chat | 用自然语言和 LLM agent 一起改歌的面板。 |
| 会话 | agent session | 一条对话线程，绑定它正在编辑的工程。 |
| 动作卡 | action card | agent 动作的「回执」：做了什么 + 变更 diff + 一键撤销。 |
| 暂存区 | staging | 待审托盘（dock ▸ AI 页签）：链 / AI 调参 / 配器的产果先停这里，等你采纳或丢弃。 |
| 调参 | tune | AI 混音面板：先测量，再给参数修改建议；勾选的才应用。 |
| 配器 | arrange | 配器面板：按模式包生成伴奏声部——试听、采纳，或带意见重生成。 |
| 命令层 | command layer | 一切编辑都必须经过的唯一事务通道——界面点击与 agent 工具同路。机器人没有后门；类似 DAW 的动作/脚本层，但强制全员走。 |
| EditBatch | — | 事务单元：一批操作原子应用、快照留痕、可撤销。 |

## 混音与其余

| 术语 | 英文 | 说明 |
|---|---|---|
| 通道 / 效果器 / 音源 / 混音台 / 录音 / 链 | dock tabs | 单轨设置、效果链、乐器路由、混音台、录音、处理链——六个 dock 页签。 |
| 导出 | export | 渲染结果：主输出、总线、分轨、MIDI——按需选。 |
| 分轨 | stems | 每轨一个音频文件，方便把歌交给别的工具。 |
| 节拍器 | metronome | 打拍器。 |
| 循环 | loop | 反复回放的播放区间。 |
| 跟速 | follow-speed | 改速度时音符随动（对比「只改谱面、音符不动」）。 |
| 预设 | preset | 现成的效果链与配器模式，每个都带出处笔记。 |

## 引擎与音色

| 术语 | 说明 |
|---|---|
| RMVPE | 哼唱转录后端（权重需另行获取——见 [setup-engines.md](setup-engines.md)）。 |
| GAME | 成品人声转录后端。 |
| FluidSynth | MIDI 渲染引擎（GM 音色库）。 |
| program / 音色 | 轨道的乐器：GM 乐器名、`vst3:` 插件、或 `sfz:` 采样器。 |
