# ADR-0015 · 宿主编辑命令层：EditBatch 事务 + git 工程版本 + 音符级 diff

- 日期：2026-08-15
- 状态：已接受
- 决策人：洛怜（拍板：编辑命令层先行；每轮一个 commit + WAV 不入库）

## 背景

docs/04 §三「完整宿主接口清单」定了优先级：**编辑命令层（undo/redo/选择集/时间线模型）> 混音/总线 > 实时音频线程 > 插件扩展**。本 ADR 定 M-V1（纯 Python + 单测，无 UI）的形态。

## 决策

1. **`tsov/host/command.py` —— 编辑命令层**：
   - 动词第一版：`add / remove / set_pitch / set_velocity / set_time / transpose / quantize_time`（track 级批量 + 单音符精确两种粒度，与 M4「标注精确、LLM 语义、程序校验」同构）。
   - `EditBatch` = 事务：在 Score 深拷贝上逐条执行；**非法命令拒绝并记录 error，合法命令全部生效**（部分应用 + 错误清单）；apply 前不脏原 Score。
   - 校验规则：越界/取值非法/start>=end/pitch 0-127/velocity 0-1——任何一条非法都明确报错，不静默。
2. **`tsov/host/project.py` —— 工程**：`Project` = Score 真相 + 快照栈 undo/redo + git 版本。
   - 工程根 `output/<name>/`：`score.json` 是真相，git 管版本；**WAV 不入库**（工程 .gitignore 自动写 `*.wav`）；Score JSON + MIDI 入库。
   - undo/redo = 批级快照栈（深拷贝 Score；原型规模够用，不写命令逆运算）。
   - **每轮 LLM 修改 = 一个 EditBatch = 一个 git commit**（message = 标签/任务 + diff 摘要）；rollback = checkout 指定版本 + 重载。
3. **`tsov/host/diff.py` —— 音符级 diff**：按 start 排序贪心配对（|Δstart|≤tol 且 pitch 相同）→ 配对中 end/velocity/deviation 变化 = changed；未配对旧音 = removed；未配对新音 = added。三色可视化（绿新增/红删除/黄修改）的数据源。
4. **工程摘要**：`Project.summary(cap=80)` —— 标题/tempo/调性/轨道/音符表（每轨封顶）+ 分段数，供 LLM 上下文节流（docs/04 §四）。

## 影响

- agent 工具（M-V2 起）从「整谱替换 edit_score」升级为「EditBatch + diff + commit」；现有 edit_score 继续作高层语义工具。
- git 用 subprocess（cwd=工程根）；嵌套仓库位于 gitignored 的 output/ 下，与主仓库互不干扰。
- M-V2 Web 壳直接消费 diff.to_dict()/summary()/log()，无需再改宿主核心。
