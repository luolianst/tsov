## 背景

tsov 已完成 M1–M8 全批（含 E 线成稿批与对话产物流批），具备「哼唱 → 转录 → 编配 → 调参/混音 → 导出」全链能力。洛怜决定开源到 GitHub「让大家玩」，以 2026-10-04 为目标发布 v0.1，并以「先跑通第一首 EDM 成品歌」为发布闸门。发布前以 grill 形式逐支敲定十项方针（目标 / 受众 / 叙事 / 英文化 / 许可 / 仓形态 / 名称 / 跑通口径 / 渠道 / 维护），本文固定化该批决策与配套机制。

## 备选方案

1. **首发范围**：私域小圈 vs 公开仓库 —— 公开发布（本选）。
2. **许可**：MIT/Apache（宽松）vs GPL 系 —— 依赖锚定（pedalboard=GPL-3.0）出局宽松许可；GPL 系收敛后选 **AGPL**（防「拿 tsov 开云端站点收费、代码不吐」）。
3. **仓形态**：新建精简仓 vs 全历史现场派 —— 现场派（本选）：开发史（任务书 → 批次 → 证据）在 agent 时代是稀缺素材。
4. **名称**：新造语义名 vs 留 tsov —— 留 tsov（查重低风险：PyPI/npm 空、软件圈零撞名）。

## 决策

1. **目标**：A 主（让更多人玩上 / 传播），B（贡献者）· C（学习）· D（自用）兼修。
2. **受众**：B 主（发布语境 = AI·agent 技术圈）；A（哼唱人群）为产品设计对象、非首批触达。
3. **叙事**：双层——标题 / 第一屏 = 产品叙事「哼一段，变成能继续编辑的成品工程」；中段 = 工程叙事（agent 原生 DAW：全功能命令层 / 可追溯可撤销 / 人与 agent 同一路径）。
4. **英文化**：B 档——英文 README + quickstart + 术语表 + 英文演示视频；UI i18n 顺延 v0.2。
5. **许可**：**AGPL-3.0**（LICENSE 入库；README 标注）。
6. **仓形态**：现场派——全历史 + 当前树全留 + README「仓库地图」+ showcase 前门；脏处仅卫生级清洗。
7. **名称**：**tsov**（`luolianst/tsov`；副标 *the shape of voice*）。
8. **「跑通」口径**：哼唱起点全链（fallback = 素材起点并记档）；产出 = 成品音频 + 可编辑工程 + 过程记录；质量线「演示可剪」（≥90 秒 / 完整 / 无明显硬伤 / 响度正常）；用户视角走 UI。第一首 = EDM（电子簇卡包参考）。
9. **渠道**：10.4 软公开 → 10.5 中文线（B站老号 + 即刻/少数派）→ 10.6 HN Show → 10.7+ 二波（Reddit / X / 评论区）。
10. **维护**：保守接法——issues 开（细看慢回）；PR 规矩（小修直接收 / 大改先 issue / 翻译特快通道）；README + CONTRIBUTING 写明 solo · best effort · 无 SLA；不开即时社区；发布周（10.5–10.7）值守。
11. **歌云边界**：v0.1 不带歌云数据库/卡（留「卡＝输入源」接口）；知识库投放（教材拆书产物）**不入公开仓**、本地保留。
12. **发布准备机制**：作者邮箱全史改写为 `271541321+luolianst@users.noreply.github.com`；知识库全史剔除（`git filter-repo`，2026-10-02 执行：231→230 提交、单一 noreply 身份、零残留；完整原件镜像备份）。
