# ADR-0026 · 实时宿主：JUCE sidecar、许可与工具链

- 日期：2026-10-17
- 状态：已接受
- 决策人：洛怜（拍板 H3/R1）+ Teto（实施）

## 背景

功能 1/2 grill 拍板 **R1 真·实时合成**，宿主选 **H3 自建 JUCE sidecar（P1 独立进程）**；离线渲染降级为导出/freeze。需要固定框架、插件 SDK、编译器与构建工具，避免后续在许可/工具链上返工。

## 备选方案

1. **JUCE 8.0.9 + 内置 VST3 SDK（GPLv3 选项）+ MSVC Build Tools** —— 现成、跨平台、JUCE 自带插件宿主模块；VST2 不做；AGPLv3 项目可选 GPLv3 路径。**选用**。
2. JUCE 商业许可 —— 无 copyleft 约束，但需付费；与当前 AGPL 开源分发不一致。
3. Reaper/Carla sidecar —— 验证快，但专有依赖/打包重，产品面不合适（grill 已排除）。
4. JUCE 9.x —— 更新，但 VST3 SDK 获取方式变化（不再随仓内置），S0 阶段不引入额外不确定性。

## 决策

- **框架**：JUCE **8.0.9**（`FetchContent` 钉版本），按 **AGPLv3** 选项使用（与 tsov AGPL-3.0 一致）。
- **插件 SDK**：使用 JUCE 8.0.9 内置 VST3 SDK，按其 **GPLv3** 选项；VST2 明确不做（SDK 已下架/不可再授权）。Steinberg 上游 VST3 SDK 3.8+ 已转 MIT，后续升级 JUCE 时可切换并简化许可。
- **工具链（实测）**：Visual Studio Build Tools 2022 `C:\VSBuildTools`（MSVC **14.44.35207** + Windows SDK **10.0.26100**）；CMake **4.4.4** 装在 `tsov/.venv/Scripts/cmake.exe`（不占全局、不需管理员）；生成器 `Visual Studio 17 2022` x64。
- **进程边界**：sidecar 独立进程，独占音频设备（ASIO/WASAPI），Python/Web 经本机 IPC 控制；实时/离线共用同一引擎图。
- **平台**：v0.2 先 Windows x64；源码保持跨平台可构建，其他平台后议。

## 影响

- **许可义务**：tsov 以 AGPL-3.0 分发；sidecar 二进制随包发布时必须提供完整对应源码与构建说明；JUCE/VST3 SDK 的版权与许可文本随包保留。发布前由洛怜复核许可文本（本节不构成法律意见）。
- **构建**：首次 CMake 配置会下载 JUCE 8.0.9（`native/tsov-host/build/_deps/juce-src`）；构建目录 `build/` 已在 `.gitignore`。
- **升级路径**：JUCE 升级需重跑 `--selftest` 与 S1 gate（VST3 加载/实时稳定性）；若升级到 VST3 SDK 3.8+（MIT），更新本 ADR。
- **风险**：JUCE 8.0.9 的 VST3 SDK 为 2024 版 GPLv3；如后续法务要求 MIT，可切 JUCE 9.x 或自定义 SDK 路径，属可控升级。
