# ADR-0023 · 过程档案撤出公开面

- 日期：2026-10-05
- 状态：已接受
- 决策人：洛怜（Teto 执行）

## 背景

ADR-0021 选择了「现场派」仓形态：全开发史 + 当前树全留（任务书 / 讨论记录 / 工作记忆 / 证据包一并公开）。v0.1.1 发布后，维护者复核公开面时判断：其中大量**过程叙事**（逐题讨论记录、任务书、会话工作记忆、验收与证据包）记录的是协作过程而非项目本身，不适合作为长期公开内容。

## 决策

1. **公开面收敛为产品面**：保留 README、LICENSE、CONTRIBUTING、ADR 决策记录、术语表、引擎搭建文档、功能表与展示资产；其余过程档案（讨论记录 / 复述单 / 任务书 / 验收 / 规划与需求 / 工作记忆 / 开发日志 / 调研笔记 / 证据包）全部撤出公开面。
2. **撤出方式为全史剥离**（git filter-repo）：不仅删除当前树，历史提交同样不可回溯；连改名前/搬家前的旧路径一并清理。
3. **过程档案整份转私有留存**（本机归档 + 完整镜像备份）。后续如需公开，以「节选 + 脱敏」方式单独整理。
4. **修订 ADR-0021 第 6 条**（仓形态）：由「全历史现场派」改为「产品面公开 + 过程档案私有」。

## 影响

- 公开仓的提交历史收敛为代码与产品文档的演进；既有提交引用（hash）随历史改写换代，README 与文档中的相关引用已同步清理。
- 复刻与协作不受影响：构建、测试、运行方式全部保留在公开面内且可复现。
- 维护者保留完整开发档案；未来可按需选择性发布。

## 补记（2026-10-05）：分发包同步脱敏

收敛后复查发现：v0.1.1「网盘一键开箱包」（构建于收敛前）因打包器对 `docs/` 整目录复制，**随包携带了已撤出类过程档案**（工作仓「隐身留存」文件被打进分发包）。分享已第一时间撤下（未扩散）。处置：

1. `make_bundle.py`：`docs/` 改为**只复制公开面（git 跟踪）文件**；新增 stage **零容忍门禁**——非公开面文件出现即中止打包。
2. 同版重打 v0.1.1 包（应用代码未变，仅内容面收敛；sha256 `8599c302…f65590`），重新分发。
3. 纪律：**对外分发物（网盘包及任何发行产物）与公开面同口径**；发布前对撤出清单做全件对账。
