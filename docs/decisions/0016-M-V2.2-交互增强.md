# ADR-0016 · M-V2.2 交互增强：空谱创作 / 快捷命令选单 / DAW 手势 / 版本对比与 base_rev

- 日期：2026-08-27
- 状态：已接受（本轮四个议题全部落地）
- 决策人：洛怜（拍板：按 ②①③④ 顺序开工；A/B 对比采用「A 路」——左槽只读、禁止旧版分叉编辑）

## 背景

docs/04 §十一 M-V2.2 议题 ①-⑤ + docs/03 Q32-Q35：宿主（M-V1/V2/V2.1）已可用，但存在四类交互缺口，本轮按用户拍板顺序一起补齐。
- ① 空谱作曲被 `_validate_llm_notes` 的 `len==0` 硬拒（守卫本意是防 LLM 清空已有谱，对空谱创作误伤）。
- ② 对话框右侧三个内联 chip 按钮渲染异常，且不易扩展。
- ③ 卷帘只有点选/缩放，没有 FL/Cubase 式直接编辑（点空白创建、拖本体移动、拖两端伸缩）。
- ④ LLM 改谱 diff 是位置对齐「猜」的（LLM 输出整谱重写）；且缺少 A/B 版本对比试听与 LLM 目标版本的显式标识。

## 决策

1. **空谱守卫语义精化（①）**：`analysis/edit.py::_validate_llm_notes(raw_notes, allow_empty=False)`。
   - `allow_empty=True` 仅当输入谱为空（`edit_score` 判定 `len(ann_notes)==0`）时开放，允许 LLM 返回空数组（= 未创作，保留原空谱）。
   - 非空输入仍硬拒空输出（防清空已有谱）；`_EDIT_SYSTEM` 增加「空谱时按反馈创作、至少 1 音」提示。
2. **快捷命令选单（②）**：`index.html #chat-chips` 内联 chip 内联按钮 → `<select id="quick-cmd">` + 执行按钮；JS 侧 `QUICK_CMDS` 数据驱动渲染（`chat.js renderQuickCmds()`），`msg|` 前缀走 LLM、`cmd|` 前缀走命令层；加命令只改数据。
3. **DAW 手势（③）**：`roll.js` 新增手势集，一次手势 = 一个 EditBatch = 一个 commit：
   - 点空白 = 铅笔创建（`add`，默认半拍，可拖长）；拖音符本体 = `move`（`set_time` + 可选 `set_pitch`）；拖左右两端（6px 热区）= `resize`（`set_time`）。
   - 复用 `EditBatch` 已有动词（add/set_time/set_pitch），不新增 op；Ctrl/Shift 仍是多选、不拖拽；拖拽中画幽灵虚线预览。
   - 未扩 `apply_annotations`（那是 LLM/标注语义路径；后续 LLM 动作数组化时再议 move/resize 注解）。
4. **版本对比试听 + base_rev（④，A 路）**：
   - `Project.score_at(rev)`：`git show <rev>:score.json` 读任意版本 Score，**不动工作区/HEAD**；坏版本返回 None。
   - `POST /api/projects/{name}/render` 支持 `rev`；`GET /api/projects/{name}/wav?rev=` 支持 `rev`——旧版渲染到工程内 `.render-cache/<rev8>.wav`（不入库，命中缓存不重渲）。
   - `ChatIn.base_rev`（默认 `HEAD`）：注入 agent brief「编辑目标版本：<rev>，请勿自行 git 回滚/切分支」；发送时前端从对比左槽取值。**A 路：左槽只读参考，禁止在旧版上发起分叉编辑**（版本树显式推后）。
   - 前端顶栏新增「版本」对比组（`#cmp-base` 下拉 + `▶ 听旧版`），`#cmp-head` 显 HEAD。

## 影响

- API 契约（docs/05）：`/render`、`/wav` 增可选 `rev`；`/chat` 增可选 `base_rev`；`state.git_log` 供对比下拉复用。
- 前端：新增 `api.wavUrlRev`；`chat.js` 发消息带 base_rev；`main.js` 填充对比下拉；`roll.js` import `api`（模块间仍经 api/state/events 交互，未破坏契约 §四）。
- 测试：`test_edit.py` +2（allow_empty / 空谱创作 mock）；`test_project.py` +1（score_at）；`test_web.py` +2（render?rev + wav?rev、chat base_rev）；全量 84 绿。
- 遗留：LLM 输出「整谱重写 → 动作数组」的意图级 diff 暂未做（议题 ④ 的下一步，与 Q29 动词层并行）；DAW 手势的多选整体移动/双击删除未做。
