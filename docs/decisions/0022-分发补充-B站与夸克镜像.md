# ADR-0022 · 分发补充：夸克镜像与 B站中文版

- 日期：2026-10-04
- 状态：已接受
- 决策人：洛怜（Teto 执行）

## 背景

ADR-0021 定的渠道排期（10.4 软公开 → 10.5 B站中文线 → 10.6 HN）进入落地时，遇到两个具体分发问题：

1. **一键开箱包 3.47 GB** —— 超出 GitHub 的载体上限（Release 单资产 2 GB、仓库单文件 100 MB），无法直传 GitHub；
2. **B站需要中文特供版** —— 与英文演示片不同的配音（曼波）、片头与剪辑节奏，以及配套物料（标题/简介/标签/封面）。

## 决策

1. **成品包分发走镜像**：夸克网盘分享 `https://pan.quark.cn/s/5492bdc95fb8?pwd=WYgU`（永久有效），链接写入 README 双语「一键开箱包」节；GitHub 侧只留源码与构建脚本（`python scripts/make_bundle.py` 一条命令重产）。
2. **B站中文版成片**：曼波配音 + B站风格片头 + 1:30 后心路历程段纯音乐 + 字幕流；成片与全部物料存**仓外运营库** `D:\My Project\tsov-运营\视频物料\bili-prep-2026-10-05\`（2026-10-08 自 `output/` 迁出；不进公开仓）。
3. **上架流程**：CDP 自动上传并填写表单（标题/简介/标签/双封面/声明）→ **存草稿** → 洛怜人工复核后点发布（发布动作保留人工）；置顶评论（含网盘链接）发布后由洛怜贴。

## 影响

- 分发面 = GitHub（源码 + 脚本 + Release 演示片） + 夸克（成品包） + B站（中文演示）。
- 复刻性不受影响：引擎自取件（`fetch_engines.py`）与打包脚本（`make_bundle.py`）均在库，任何人都能重建等价成品包。
- README 中镜像链接为可复制文本；B站简介/评论外链不可点击（平台行为）属正常。
